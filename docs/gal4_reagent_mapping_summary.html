What counts as a GAL4 match?

The script recognizes exact GAL4 labels and common alternate formats, then follows FlyBase allele → construct → insertion links so the same driver can resolve when publication and stock-center names differ.

Example

Direct GAL4 text is treated as a driver signal and compared with stock-component names.

If an exact published construct has no orderable stock, the script may recommend the simplest current BDSC driver from the same promoter family. These rows are explicitly labeled as candidate substitutions, never exact matches. Every input remains visible on the Coverage sheet.

What appears in the workbook?

Reagent
Input GAL4 symbol, resolved driver genotype, stock genotype, stock center, stock number, and FBst ID.
Evidence
Phenotypes as {PMID/PMCID, phenotype} pairs, plus qualifiers, phenotype-record genotypes, titles, authors, journals, and years.
References
One row per publication, listing the associated GAL4 symbols, stocks, collections, and phenotypes.
Coverage
One row per input symbol with exact/alias, candidate-substitution, or unresolved status so missing drivers cannot disappear silently.
